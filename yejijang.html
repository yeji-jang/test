개발을 시작한 계기

AI에 관심을 갖게 된 계기

AI 컨설팅과 제조데이터 표준화 업무를 하며, 사람이 반복적으로 검토하던 데이터 정합성 작업을 LLM이 상당 부분 대신할 수 있다는 것을 실무에서 직접 확인했습니다. 그때부터 AI를 단순히 써보는 것이 아니라, 하나의 서비스로 연결하는 일에 관심을 갖게 되었습니다.

개발하면서 배운 것

데이터 분석 과정과 AI 부트캠프를 거치며 Python과 SQL로 데이터를 다루는 법, LangChain과 Ollama로 로컬·클라우드 LLM을 연결하는 법을 익혔습니다. 청약정보 챗봇 프로젝트를 통해서는 프롬프트를 설계하는 일과 실제로 동작하는 서비스로 만드는 일 사이의 간극을 몸으로 배웠습니다.

AI를 실제 서비스로 연결해본 경험

데이터야 놀자 · 2023.10

청약정보 GPT 챗봇

  • Azure
  • GPT
  • Prompt Engineering

부동산 청약 공고 PDF를 GPT 모델에 연결해, 사용자의 청약 관련 질문에 답변하는 챗봇을 구현했습니다. Azure 클라우드 환경에서 GPT 모델을 호출하는 구조를 구성하고, 질문 의도에 맞는 답변을 이끌어내기 위해 프롬프트를 나누어 설계하고 반복적으로 개선했습니다.

  • 문제 정의 — 청약 공고 PDF는 형식이 제각각이라, 사용자가 원하는 조건을 그대로 질문해도 GPT가 정확히 참고하기 어려웠습니다.
  • 접근 방식 — 질문 유형별로 프롬프트를 분리하고, PDF에서 추출한 청약 정보를 GPT에 전달하는 흐름을 설계했습니다.
  • 결과 — 실제로 Azure 위에서 동작하는 챗봇 데모를 완성하며, AI를 API 호출 이상의 서비스 흐름으로 연결하는 경험을 얻었습니다.
